# Interview-practise-system
HRInterviewPro is an AI-powered web application for interview preparation.The tech stack includes Python, Flask, SQLAlchemy, SQLite, Flask-Login, HTML, CSS, JavaScript, and the Web Speech API. To run the application, you need Python 3.9 or higher and pip.  and run python app.py. The app opens at http://127.0.0.1:5000.
