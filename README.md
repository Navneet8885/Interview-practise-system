# Interview-practise-system
HRInterviewPro is an AI-powered web application for interview preparation, developed by Navneet Kaur as a college project for the Artificial Intelligence course. It helps users practice job interviews through an interactive chat-based system with intelligent feedback.

The app includes 12 interview questions across four categories: Behavioral, Technical, Situational, and Leadership. Users can type answers or speak using voice input via the Web Speech API. Questions can also be heard aloud through text-to-speech. Each answer receives a score from 1 to 10 with constructive feedback generated by an AI-based evaluation engine that analyzes answer length, structure, and content quality.

Features include secure signup and login with password hashing, a dashboard showing total answers, average scores, and category performance, version history for retried questions, and a responsive dark-themed interface.

The tech stack includes Python, Flask, SQLAlchemy, SQLite, Flask-Login, Werkzeug, HTML, CSS, JavaScript, and the Web Speech API.

To run the application, you need Python 3.9 or higher and pip. Clone the repository, create a virtual environment, install dependencies from requirements.txt, and run python app.py. The app opens at http://127.0.0.1:5000.
